What each one measures

    List guidelines

    How models get placed, how points are awarded, and how benchmark scores are read.

    What the list is

    The Model List ranks language models by measured capability. Position #1 is the strongest model anyone has benchmarked, whether or not you can use it. Availability is shown as a status badge and never affects placement. Placements are decided by the list team from independent benchmark runs, blind-preference arenas and published system cards, then argued about in public.

    The tiers

    • Main list (#1–#15). Current frontier. Full list points.
    • Extended list (#16–#30). Still competitive, usually a generation behind or a smaller tier of a main-list family. Reduced points.
    • Legacy list (#31+). Kept for history. No points. Models never leave the site once placed.
    • Watchlist. Announced models with no benchmark result yet. Unranked, no points, listed at the bottom so nobody is surprised when they arrive.

    Placement rules

    1. A model qualifies once at least one benchmark result exists for it: independent, vendor-reported, or from a system card. Released, restricted, preview and internal models all qualify.
    2. Internal and restricted models are placed on the numbers their lab has published. They carry the widest error bars on the list and a red status badge, and they are re-placed the moment an independent run lands.
    3. One entry per model. Reasoning modes, effort levels and "thinking" variants are settings, not separate models. A restricted variant gets its own entry only when it posts results the public variant does not.
    4. Vendor-reported numbers are shown with a red tag. They can place a model but never move it above a model with independent results on the same benchmark.
    5. A model that is deprecated or removed from the API drops to legacy on the next update.

    Reading a benchmark row

    Each model page lists its benchmark scores. Every row shows who ran it (independent in green, vendor in red, community in blue), where the score stands against every other model on the list that has the same benchmark, and the source. The Benchmarks tab lays the same numbers out as a grid with the best score in each column highlighted.

    Index scales

    Artificial Analysis rescaled its Intelligence Index to v4.2 on 4 September 2026. Fable 5.1 reads 66 on v4.1 and 57 on v4.2. The list quotes v4.2 wherever it has been published and marks older entries v4.1. Epoch's Capabilities Index (ECI) is quoted where Epoch has run the model.

    Not tracked yet

    Records. On a list like this a record would be the best thing built with a single model in a set period, not a benchmark score. That is subjective enough that the list does not track it yet. If it ever does, it will be a separate section with its own rules, and benchmark scores will stay benchmark scores.
